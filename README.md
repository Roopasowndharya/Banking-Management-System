# Banking_Management_System
# 🏦 SecureBank Console Application

A Python-based console banking application developed as part of the **Python Backend Developer Roadmap**. This project simulates the core functionalities of a banking system through a Command Line Interface (CLI). It is designed using a modular architecture and follows Object-Oriented Programming (OOP) principles to provide a clean, maintainable, and scalable codebase.

The application allows users to perform essential banking operations such as creating accounts, depositing money, withdrawing money, checking account balances, and closing accounts. During Week 1, all account information is stored in memory using Python dictionaries, making the application lightweight and ideal for understanding backend fundamentals before moving to databases and web APIs.

This project serves as the foundation for upcoming enhancements such as transaction management, data persistence using JSON, FastAPI integration, SQLAlchemy, authentication, authorization, automated testing, and Docker deployment.

# 🎯 Project Objectives

The primary objectives of this project are:

- Develop a console-based banking application using Python.
- Understand the implementation of CRUD operations.
- Apply Object-Oriented Programming concepts.
- Use Python Dataclasses for representing account models.
- Store and manage account data using dictionaries.
- Handle errors using custom exceptions.
- Write clean, modular, and reusable code.
- Build a strong foundation for backend development with FastAPI.

# ⚙️ Functionalities

### 1. Create Account
Creates a new bank account by accepting the customer's name and initial balance.

### 2. Deposit Money
Allows users to deposit money into an existing account after validating the amount.

### 3. Withdraw Money
Withdraws money from the selected account after checking the available balance.

### 4. Check Balance
Displays the current account balance.

### 5. Close Account
Deletes the selected account from the banking system.
